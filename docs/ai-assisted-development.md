# AI-assisted development

The project plan permits AI assistance for small, reviewable tasks. For each functional slice, record the acceptance criteria first, review generated changes line by line, verify dependency APIs against installed packages or official documentation, and run independent lint, type, test, and migration checks. See [the project plan](project-plan.md), section 23.

AI-generated output is a draft. The author remains responsible for understanding concurrency, privacy, failure behavior, and trade-offs before presenting the project as their work.
