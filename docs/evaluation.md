# Evaluation design

Evaluation is planned for a bounded, synthetic support-classification dataset. Cases, runs, evaluator versions, and the exact release/configuration version will be recorded so comparisons can be reproduced. See [the project plan](project-plan.md), sections 10 and 12.

The report should show paired stable/candidate quality and operational measures, plus expected, missing, skipped, failed, expired, and interrupted outcomes. With content capture disabled, the evaluator should score available outputs before discarding them. No evaluator, dataset, or report is implemented in this scaffold.
